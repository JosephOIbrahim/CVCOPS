# Release gate v0.1

A proposal from the planning panel of 2026-11-10, not adopted. The blueprint's release-gate row governs; this brief
adds the order, the files and the checks. Graph and conventions: `docs/missions/GRAPH.md`.

**Goal.** A README with measured numbers, limits and the one-file install, proved from a fresh clone, and one plate of
Joe's baked through the artist's Bake function.

**Entry.** M4 is closed and committed. The release has no threshold rows and no `mission.txt` change: the M0 to M4
lock stands. STATE holds the DEC.quarter verdict.

**Done when.** On the release commit, with a clean tree, `uv run python tools/check.py` and
`uv run python tools/check.py --houdini` exit 0 on the workstation, and `--selftest` still passes. Rung 3 is recorded
as not applicable unless M6 ran. The README carries measured numbers, limits and the one-file install. One plate of
Joe's bakes with every pair fresh, and he has signed off in his own words. Decision 0001's release-gate box is ticked.

**Tier.** Heavy (the blueprint leaves it blank). Rung 2, the installer's build and Joe's plate all hold the licence,
and the sign-off is his.

## How the session runs

1. **Read** `CLAUDE.md`, `docs/BLUEPRINT.md`, `docs/FACTS.md`, `docs/STATE.md`, decisions 0001 to 0004 and this brief.
2. **Two read-only checks at the gate.** The parked audit (nothing from BLUEPRINT section 12 or decision 0003 started)
   and the packages-folder lookup (where Joe's desktop Houdini reads packages on this machine).
3. **Pause.** `WAITING:` with the plan, the new files, decision 0005 as proposed, the release goal line, and the
   asks: candidate branch and fresh clone, install defaults, licence, and the plate with what may be quoted. Stop.
4. **Build.** The version moves to 0.1.0 on main. The `install.py` lane works beside it, and main re-runs M3's
   package check on the candidate. Main copies the lane back and runs `check.py`.
5. **Prove the install from a fresh clone** of the `release/v0.1.0` candidate branch: the installer, rung 1 and
   rung 2.
6. **Bake Joe's plate** through `bake_timing.py`, in one call if it fits in 600 s, else in chunks. Verify every pair
   fresh after the last chunk.
7. **Review scene and audit.** Render arrows, B pulled onto A and the difference; audit the receipts into a numbers-only
   summary.
8. **Sign-off.** Joe installs, opens the review scene, reads the audit table, signs off and closes Houdini.
9. **README and docs.** Limits, install, numbers (the numbers run grades the rows through hython, after the sign-off),
   the docs sweep, then the one reviewer pass.
10. **Close.** Every rung that applies, decision 0001 ticked, the hython identity, STATE and FACTS last. Joe merges,
    tags and publishes outside the graph.

Budget: one session. The plate bake and two rung-2 runs dominate it.
