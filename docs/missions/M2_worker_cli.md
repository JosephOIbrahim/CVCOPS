# Mission M2: the worker CLI

A proposal from the planning panel of 2026-11-10, not adopted. The blueprint's M2 row governs; this brief adds the
order, the files and the checks. Graph and conventions: `docs/missions/GRAPH.md`.

**Goal.** `python -m cvcops flow` reads `analysis.####.exr`, writes `flow.####.exr` and its receipt atomically, and
`python -m cvcops verify` reports each pair fresh, stale or missing.

**Entry.** M1 is closed (commit `70b19e5`). The committed `tests/thresholds/mission.txt` lists M2, and Joe has
answered `M2.gate.policy` and `M2.io.mode` in the start sitting. If `mission.txt` does not list M2, write `WAITING:`
and stop.

**Done when.** `uv run python tools/check.py` passes the M2 row (EXR write then read, the transport pattern,
bit-exact) and the agent's own tests in `tests/unit/`: a CLI round trip, an interrupted write, and stale on a changed
`cv2` version. `uv run python -m cvcops capabilities` shows `flow` and `verify` available. `docs/STATE.md` holds the
closing command and the tail of its output.

**Tier.** Light (blueprint section 8). Attended by default. Unattended only under OD-02's conditions, because that
route takes three sessions.

## How the session runs

1. **Read** `CLAUDE.md`, `docs/BLUEPRINT.md`, `docs/FACTS.md`, `docs/STATE.md` and this brief.
2. **Check the entry.** `git show HEAD:tests/thresholds/mission.txt` lists M2. Take the baseline: plain
   `uv run python tools/check.py` exits 1 with exactly one problem, the `exr_roundtrip` row failing on
   "write_flow_exr is Mission 2's work".
3. **Probe and draft in parallel.** The OpenEXR API probe runs in scratch files (a read-only subagent if Joe adopted
   OD-01, on main otherwise). Main drafts decision 0004 as `Status: proposed`.
4. **Pause.** The first line of `docs/STATE.md` becomes `WAITING:` with the plan, the file list, decision 0004 and
   OD-03 to OD-11. Stop.
5. **Build, on Joe's OK.** The `io_exr.py` lane and the receipt side's first node run side by side; main copies the
   lane back and runs `check.py`. Then the cache key, freshness, `flow`, `verify`, the end-to-end tests and the
   manifest flip, all on main, one file at a time.
6. **Time on an idle machine.** Run 1080p and 4K in the foreground with the turn held open, nothing else running.
7. **Review once.** The single reviewer pass. Each gap is fixed with a test or recorded in STATE.
8. **Close.** Rung 1 with the M2 row, FACTS, the STATE entry. Joe commits.

Budget: one session.

## What each task must show

- **`M2.gate.policy`.** Settles OD-01. If adopted: read-only subagents may run except during timed runs; at most one worktree writer at a time, in a sibling folder outside the repository (for example ../CVCOPS-lanes/&lt;lane>), which Joe adds with /add-dir or --add-dir in each session that uses it and never by editing .claude/settings.json, a judge file; a lane never commits, merges or pushes: main copies the lane's named files into the main tree and runs uv run python tools/check.py, then removes the worktree. Joe also edits or annotates BLUEPRINT section 9's 'no fan-out' line, or records in STATE that it stands against the new CLAUDE.md line until the release docs sweep. In the same sitting Joe updates CLAUDE.md's build command to 'uv run python probes/hython.py houdini/build/build_hdas.py --out houdini/otls'. If he declines, every subagent and worktree node runs on main in the listed order and only the reviewer passes stay subagents. Every readonly_subagent or worktree_writer node except the reviewer passes depends on this gate.
- **`M2.io.mode`.** Attended (default, OD-02): M2.io.plan collects the answers at its pause. Unattended takes three sessions (an attended one to draft and accept decision 0004, the run, an attended one for the review, the values run and the merge), so CLAUDE.md's third-session stop applies unless Joe writes the three-session budget into STATE first. It also needs a dry run showing that an edit inside the launcher's .claude/worktrees/m2 worktree succeeds with nobody to approve a prompt (FACTS K5, K9). Then every M2 node runs main_only inside the one print-mode agent with no subagent; M2.judge.review and the env-prefixed values run happen in Joe's attended session before merge, which needs 'No judge file touched' and check.py passing on his checkout.
- **`M2.io.exr_probe`.** A short table cited in M2.io.plan and recorded in FACTS by M2.judge.close. Uses the same OpenEXR.File(header, channels) call as evidence/thresholds_reference.py (bit-exact, FACTS P6). It shows how OpenEXR names channels it writes itself, not what ROP Image writes; M3.io.reader_pin settles that.
- **`M2.contract.decision_0004`.** Fixes: (a) a sidecar &lt;prefix>.json beside &lt;prefix>.####.exr with its own schema id, cvcops.analysis_sidecar.v1, defined in this record and in ARCHITECTURE, not under docs/contracts and never the receipt's id; it may set only analysis.luminance_weights, gain, gamma, scale, color_space and frame.fps; the worker finds it from --in. (b) No flow option, no controls.json entry, no test_controls.py line, no manifest argv change. Rejected: new flags (test_every_flow_option_has_a_control would demand maps_to.cli, and analysis_scale's string choices collide) and EXR header attributes, because ROP Image's metadata export is untested on 22.0.492, its key names are unknown, and parsing it would tie the worker to ROP Image. (c) No sidecar: scale 1.0, defined as 'the analysis image is the source as given', the rest null. (d) Error rule OD-04. (e) Key and identity OD-06; values that change the analysis image (weights, gain, gamma, scale) change its digest, so the key catches them; fps alone does not. (f) timings keys OD-07. (g) verify OD-05. (h) progress OD-09, flushed per line. (i) jsonschema dev-only OD-08. (j) Field split: M2 fills every required field without Houdini; only M3's export fills weights, gain, gamma, a scale other than 1.0 and fps; color_space null in v0.1. Number 0004 goes to this record; the release's distribution record becomes 0005.
- **`M2.io.plan`.** The plan names every file M2 writes and nothing else: src/cvcops/io_exr.py, src/cvcops/receipt.py, src/cvcops/cli.py, src/cvcops/capabilities.json; tests/unit/test_io_exr.py, tests/unit/test_receipt.py, tests/unit/test_sidecar.py, tests/unit/test_worker.py, tests/unit/test_manifest.py, tests/unit/test_synapse_mapping.py, tests/unit/test_cli.py; docs/decisions/0004-analysis-sidecar.md, docs/ARCHITECTURE.md, docs/CONTROLS.md, docs/STATE.md, docs/FACTS.md. No judge file, dependency or Houdini node; temporal.py untouched. Cites the OpenEXR table. If the committed mission.txt does not list M2, writes the pause line and stops. Under unattended mode this node is only the listing check and baseline; the answers come from committed STATE.
- **`M2.io.flow_exr`.** write_flow_exr accepts only float32 (H, W, 3), checks dtype and shape, never values (transport pattern holds about +-2300 and a 1e-3 marker). Writes R, G, B FLOAT, ZIP, scanline with the reference's call. Temp file from tempfile.mkstemp in the target's folder, leading-dot name, never matching flow.####.exr or flow.####.json; descriptor closed before OpenEXR opens it; then os.replace, retried a bounded number of times over about a second on PermissionError (File COP holding the file, OD-11), then raises; temp removed on any exception. read_flow_exr returns float32 (H, W, 3), ContractError on a missing or non-FLOAT channel. Tests: bit-exact transport round trip; float64 and float16 refused; with os.replace patched to raise there is no target, no temp and an earlier target is intact.
- **`M2.io.analysis_reader`.** Returns uint8 (H, W) as np.clip(np.rint(x \* 255.0), 0, 255), so k/255 comes back as k. Alpha (A, \*.A, \*.a) set aside; then exactly one channel of any name, or an R, G, B trio bare or under one common layer prefix in either case, bit-equal. FLOAT or HALF. A data window strictly containing the display window is cropped and reported. ContractError listing channel names for: unequal R, G, B; two or more unrelated channels; UINT; NaN or infinity; a data window not covering the display window; multi-part files. Optional report feeds analysis.warnings. No Mono channel name guessed. Complete within M2, because its source hash is in every cache key. Tests write each layout and every refusal (OD-10).
- **`M2.contract.sidecar_reader`.** receipt.SIDECAR_SCHEMA is cvcops.analysis_sidecar.v1 and receipt.SIDECAR_FIELDS lists the six paths. read_analysis_sidecar(pattern) maps &lt;prefix>.####.exr to &lt;prefix>.json; no file gives scale 1.0 (the source as given) and nulls; ContractError on another schema id, a malformed file, an unknown key or a measured field (clipped_share, grey_levels, warnings, image). A test binds the reader to controls.json without editing it: every v0.1 control whose maps_to has 'prep' carries maps_to.receipt under analysis.\*, and the reader accepts that path (luma_weights, gain, gamma, analysis_scale).
- **`M2.contract.receipt_assembly`.** cv2_identity() returns (cv2.\_\_version\_\_, sha256 of getBuildInformation() with normalised line endings), read at call time, the only place the build is read, patchable. request_params() and expected_cache_key() call contract.cache_key unchanged with input digests, param_digest(params.values = {tolerance_px, mask false, LF-normalised source hashes of read_analysis_exr, estimate_flow, validity}), recipe_source_sha256 (unchanged under CRLF), requested backend, cv2 version and build hash, CONTRACT_VERSION; engine version not in the key and read from cvcops.\_\_version\_\_ at call time. build_receipt() fills all 15 required fields plus output, params, summary (valid_share, median and p99 motion over valid pixels) and timings_s keys read, hash, flow, validity, write, total; clipped_share and grey_levels are the worse of A and B; paths absolute POSIX. write_receipt() checks required keys, enums, if/then rules and sha256 patterns by hand, then temp in the same folder and os.replace; an invalid receipt is never written. Tests validate ok, error and sidecar receipts with jsonschema Draft 2020-12 (dev) against the locked schema; key changes with cv2 version, build info, recipe source, validity source and tolerance, and not with thread count or a moved folder; a fault before os.replace leaves no temp and no final file.
- **`M2.contract.freshness`.** freshness(receipt_path, expected_cache_key, flow_path) returns (state, reason): missing when no receipt or no flow file; stale when unreadable or malformed, status error, another cache_key, output.sha256 differs from the file on disk, or an input frame is gone; else fresh. Expected key from request flags when given, else the receipt's recorded request. verify_report() returns {frames, counts {fresh, stale, missing}, pairs [{a, b, state, reason}]} (OD-05). flow's skip calls the same function. Tests cover every cause, a patched cv2_identity, and a crash between the flow os.replace and the receipt os.replace.
- **`M2.io.flow_cmd`.** Preflight before any write: frame_pairs; every analysis frame first..last+1 exists after #### expands (zero-padded to the count of #), else exit 1 naming them; backend per OD-04 (cpu sets cv2.ocl.setUseOpenCL(False); cuda with no CUDA device and opencl with no usable device exit 3; opencl with a device exits 1 naming Mission 6; nothing written); cv2 or OpenEXR import failure exits 3. Per pair: hash inputs, expected key, skip when receipt.freshness says fresh; read A (reusing B), read B, stats; merge the sidecar; estimate_flow forward (timings flow), backward plus check (timings validity); compose float32 u, v, valid at analysis size, never resized; delete the old receipt, write_flow_exr, write_receipt last. Failure after both frames are hashed and read writes an error receipt and removes the old flow file; earlier failure writes nothing; the run goes on and exits 1. One progress line per pair on stdout, printed with flush=True so a pipe sees it at once; reasons on stderr (OD-09). No new flow option; controls.json and test_controls.py untouched. Unit tests here cover preflight, skip and error receipts; tests/unit stays well inside 120 s.
- **`M2.io.verify_cmd`.** Optional --recipe, --backend, --tolerance (default None, meaning as recorded). Hashes current inputs, recomputes the key with the current cv2_identity, recipe source and contract, calls receipt.freshness. --json prints verify_report's shape; otherwise one line per pair. Exit 0 all fresh, 1 otherwise, 3 when cv2 or OpenEXR cannot import. Writes nothing (listing and mtimes compared). Tests: stale on changed cv2 version and fresh after re-run; stale on changed input bytes and on changed --tolerance; missing when the flow file or receipt is deleted.
- **`M2.judge.unit_tests`.** No GPU or Houdini; frames about 64x96. (1) Round trip: analysis.1001-1003.exr as RGB float32 k/255; cli.main flow 1001-1002 returns 0; R and G byte-equal estimate_flow, B the validity mask; each receipt validates against the locked schema; cache_key recomputed; requested == ran == cpu; recipe.source_sha256; stats equal analysis_stats (worse of A and B); timings_s keys read, hash, flow, validity, write, total, all >= 0; read_analysis_exr returns the original uint8; verify --json all fresh; a second run changes no byte or mtime; one 'python -m cvcops flow' subprocess with timeout 60 exits 0 and its progress lines arrive before it exits. (4) cuda and opencl refused per OD-04 with the device probe monkeypatched (never the real 4090): exit 3 or 1, nothing written. Whole file under 10 s; every subprocess has a timeout.
- **`M2.contract.consumer_promises`.** flow and verify available; flow inputs and argv gain tolerance (number, default 1.0); verify argv carries recipe, backend, tolerance; exit-code texts follow decision 0004. test_cli's fill dict gains {tolerance}; a test asserts both available with exit_codes 0, 1, 3, and runs every available operation's filled argv to exit 0 on tiny frames. test_manifest ties every flow and verify option except --help to a manifest input. test_synapse_mapping checks each 'From the receipt' path exists in the locked schema and in a round-trip receipt (null only for color_space and sidecar fields).
